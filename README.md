# 💬 AI-Powered Interview Preparation Platform
This project is an advanced full-stack application that analyzes resumes, self-descriptions, and job descriptions using the Gemini API to identify skill gaps and generate personalized technical and behavioral interview questions.

# 📚 Key Features
Resume & Job Description Analysis
The platform processes candidate profiles and job requirements to pinpoint exact skill gaps and tailor targeted preparation paths.

Dynamic AI Interview Generation
Leverages the Gemini API to dynamically generate custom technical and behavioral interview questions based on unique user inputs.

Secure Authentication & Validation
Implements robust RESTful APIs with JWT-based authentication and structured AI response validation using Zod.

Resume Tools & Report Management
Features file uploads via Multer and generation tools via Puppeteer, accompanied by a responsive React interface to generate, view, and revisit comprehensive interview reports and history.

# 🚀 How It Works
User Input: Candidates upload resumes or provide self-descriptions alongside target job descriptions.

AI Processing: The system evaluates data, validates structures with Zod, and interacts with the Gemini API to curate questions and identify skill discrepancies.

Report Generation: Secure backend endpoints compile results, tracking session history and rendering interactive dashboards via the React frontend.

✅ Benefits
Provides targeted, role-specific interview preparation driven by advanced generative AI
Ensures data security and robust backend validation using modern full-stack practices
Streamlines resume optimization and progress tracking in a unified user-friendly platform
